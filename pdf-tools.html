        Ubah Word ke PDF

        Ubah dokumen Word (.docx) menjadi PDF. Diproses di browser kamu, file tidak diunggah.

        Klik untuk pilih file atau seret file Word (.docx) ke sini
          Unduh langsung: PDF terunduh otomatis, tetapi tiap halaman berupa gambar sehingga teks tidak bisa diseleksi. Cetak ke PDF: dialog cetak browser terbuka, pilih "Simpan sebagai PDF". Hasilnya lebih tajam dan teksnya bisa diseleksi (disarankan di komputer). Tampilan mengikuti font di perangkatmu, jadi bisa sedikit berbeda dari di Word. Hanya mendukung .docx; untuk file .doc lama, simpan ulang dulu sebagai .docx.
